# Windows 真机验收

## 今晚首验

1. 解压便携包，先在 CAD 未启动时运行 `bin\SWGrade.Probe.exe`，记录 Windows build、.NET Framework Release、CAD 注册及连接诊断。运行 `SWGrade.Desktop.exe`，确认「作业批改」能打开本地 SQLite，且「单件分析」能给出 CAD 未启动的诊断。
2. 启动 SOLIDWORKS 2026，留一个实例。使用本机创建的无外部引用零件运行下列脚本，并用 CAD 原生质量属性核对真实读数。

   ```powershell
   .\tests\Verify-ModelRead.ps1 -ExpectedYear 2026 -Model 'C:\Samples\part.SLDPRT'
   ```

3. 在桌面「单件分析」选择同一文件为当前件并读取，检查配置、实体数、单位、JSON 与源文件保护。用无材料、错误配置和损坏样本分别确认降级与失败行为。检查已有 CAD 文档和 CAD 进程仍开放。
4. 在「作业批改」建一个临时验收作业，导入至少两份有效零件与一份损坏零件，检查单件错误、下一个文件继续执行、待复核分值及人工确认。关闭并重启桌面后，检查 SQLite 记录、规则快照、终评历史、班级 CSV 和单件 HTML 的终评一致。
5. 使用完整样本集跑至少 20 份，覆盖暂停后继续、取消剩余、失败重试、同内容独立记录和重新打开历史。读取前后对标准件和学生件各自保存 SHA-256 与 `LastWriteTimeUtc`。
6. 在「设置」开启「开发模式」后点「重新检测」，记录 Utilities 对象及接口状态。后续须用两份具体样本验证实际比较许可及报告，再接入几何分值。

## 已打开的零件入口

- 在 SOLIDWORKS 打开两份已保存零件，再新建一份未保存零件。确认「使用 CAD 当前零件」随 CAD 活动文档选择正确；列表显示各零件的名称、路径、配置和保存状态。装配体、工程图及隐藏的引用零件不出现在选择器。
- 在活动的已保存零件上做一次可撤销的编辑。确认读取得到磁盘版本，并提示 CAD 中需保存的变化。检查原文件 SHA-256 和最后写入时间，以及 CAD 文档仍打开、修改仍待保存。
- 用已有两个配置的零件切换到非默认配置，确认从打开文档读取时采用活动配置。显式输入另一已保存配置时确认优先使用该值。
- 在选择器打开后从 CAD 关闭所选零件，确认读取阶段提示重新选择。有独立窗口的机房环境可单独测试。
- 验证「从 CAD 选择」标准件及「导入 CAD 零件」后可完成作业预检和批改。

## 白板布局与三维预览

- 启动时查看概览的连接状态。在设置页展开检测明细。确认可切换到单件分析或作业批改，连接不可用时显示实况。
- 在引导页分别从 CAD 或磁盘选参考件与当前件。验证互换后文件及配置同时交换，仅选当前件可读取。用明显不同的脱敏样本核对可解释的参数差异，展开异常并检查 JSON。
- 确认结果页能显示真实网格、旋转、缩放、平移和重置。切换两份模型，核对姿态和相对尺度。网格不可取时应有明确提示，已读取的数值仍可查看。
- 检查作业批改左侧提交列表及右侧证据、复核面板。验证窄窗口下的侧栏、滚动和按钮操作。

## 结果页专项复验

- 优先在用户截图所示的 SOLIDWORKS 2025 SP1.2 上，用同一脱敏零件与保存配置各读两次。核对体积、实体面积、面数和质量，区分无材料与读取失败。检查叠加视图无重复面、条纹和虚假差异提示。
- 用修改厚度、移动孔位、不同剖分网格及整体平移的真实样本核对灰色交集、红色多余、蓝色缺失和「仅看差异」。同时检查尚未取得实体证据时的目测回退提示，以及多实体和无网格样本的单件回退。
- 用标准孔板和移孔件复验坐标切换。选择「形状刚体对齐」后，无法验证重合时程序应自动显示已核对的原始坐标差集，并标明对齐待复核。默认和正视叠加均应看见红、蓝差集，各 50.26548 mm³。关闭高亮应恢复正常遮挡，「仅缺少」应聚焦蓝色差集。
- 用等效孔板为参考件、删孔板为当前件复测同一路径。应只有红色多余 50.26548 mm³，蓝色缺失为零。交换两件后应只剩蓝色。分别查看计算完成后的当前件、参考件侧和点击读数，检查区域实际着色。用同形样本核对容差内的全绿色，并修改容差后检查模型颜色随色带更新。
- 保存同一参考件的作业，比较同一对样本在「评分试算」与批量中的得分、扣分依据及需复核分。切换错误参考件或配置时，核对试算不会生成分数。关闭开发模式后结果页仍能完成教师操作。


## 钣金自动识别与展开

- 用一件带孔的钣金折弯件和对应的展开配置分别读取，验证自动识别、折弯态、正视展开图和相互切换。核对源文档仍保持原状态，SHA-256 和最后写入时间一致。运行普通零件、手动按钣金、手动按普通零件三种分支。
- 对照一份相同文件、一个修改孔位置但面积接近不变的样本、一个修改面积的样本。分别查看展开叠加、参数状态和评分试算，随后用同一对样本验证批改队列。
- 检查无平板型式的导入体、多实体钣金和无法重建的配置，确认提示清楚，展开图不会回退显示折弯网格。


## 通知复验

在 Windows 上打开作业管理，先保持标准件未选，连续点击自带的保存按钮两次。应新增两条同文错误，各自带触发时间，最新在底部。关闭其中一条后另一条可见。「清除全部通知」后重新触发应出现新卡片。切换页面后再试手动连接检测或结果导出，验证共用通知仍可关闭。在关闭系统动画、125% 缩放和最小窗口尺寸下核对通知可滚动，关闭按钮可见，作业保存入口仍可使用。
