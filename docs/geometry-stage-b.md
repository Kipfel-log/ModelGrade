# 阶段 B · 实体比较与评分

桌面分析和批量批改复用阶段 A 的 SOLIDWORKS B-Rep 服务。比较在同一 STA CAD 会话内执行。评分接收体积守恒校验通过、且与分析快照的哈希、配置、CAD 修订版和体积一致的证据。批量在同一文件内容与配置可验证时使用旧有快捷路径，其余可评估提交执行原生比较。历史成绩、人工终评和既有权重保留。

已有作业默认保留原始 CAD 坐标。教师可在作业高级设置选择形状刚体对齐；该策略仅接受经双向差集与交集验证的重合变换。对齐失败或试算采用的坐标策略与作业不同时，几何分待复核。

比较证据与成绩一起保存，包含双方哈希及配置、CAD 修订版、变换矩阵、差集与交集体积、原始错误码和状态。体积用 m³，差异率为（缺失体积 + 多余体积）÷ 参考体积，编辑器用百分比表示容差。

Windows x64 Release 构建及 CloudChecks、WorkflowChecks 通过。原生布尔实验的 Windows 2026 真机记录见 [阶段 A](geometry-stage-a.md)。桌面显示与最终流程验收在后续阶段记录。
