# 作业管理与局部窗口优化验收

作业页以选标准件、选评分方式、保存为主流程。详细权重、各项误差、质量与材料检查和高级配置映射放在独立的折叠区。标准模型配置通过 SOLIDWORKS 读取，分析继续在独立 STA 处理临时副本。

## 作业设置

1. 在 SOLIDWORKS 中制作或打开一个含两个命名配置的脱敏零件，激活其一并保存。打开 SWGrade，进入「作业管理」，从文件或从 SOLIDWORKS 选择此零件。核对下拉框包含两个实际名称，默认选中文件保存的活动配置。另选一个，保存后执行「标准件预检」，核对实际读取的配置。
2. 将含同名配置的学生件与仅有其他配置的学生件放入同一批次。前者应自动选择规则匹配的配置，后者应进入「待复核」并且没有自动评估分值。在「逐项对照」点「为所选学生选择配置」，核对名称列表，选中一个以后开始或继续队列。验证应用重启后已选配置与两次尝试记录仍在。
3. 切换「误差要求」的严格、标准、宽松，在高级设置核对各项相对容差为 0.01%、0.1%、0.5%。这些是待实测的建议初始值。质量开启检查后显示。在「标准」下将体积相对容差调为 0.2%。若体积绝对容差低于 0.2 cm³，100 cm³ 的实时示例应显示 99.8 至 100.2 cm³。在高级设置将体积绝对容差设为 0.6 cm³，示例应变为 99.4 至 100.6 cm³。
4. 默认保持高级设置折叠，分别测试直接保存、勾选「还要检查指定建模操作」后选圆角并保存、勾选后未选操作时显示下一步。核对新作业结果模式为 60/40/0，选定建模操作后为 60/25/15。展开高级设置后再测试编辑三个权重。确认总分不足或超过 100，以及超过两位小数时会得到清晰反馈。测试保留人工复核与显式转给参数两条路径。可在关闭程序后备份 SQLite，再核对规则快照。相对值使用比例，三个绝对值分别以 m³、m² 和 kg 保存。
5. 用更新前的脱敏本地数据库副本打开旧作业，确认旧分数和结果仍可查看。「沿用当前规则」应载入原配置、容差及权重。保存按钮会生成新的作业快照。

## 侧栏、标题栏和检测

- 在窗口变窄、变矮、最大化及还原时，手动展开和折叠侧栏。核对固定在底部的设置入口、图标居中、鼠标悬停 Tooltip 和页面切换。检查独立标题栏左上仅有图标与 SWGrade，原生最小化、最大化、还原和关闭正常。
- 先关闭 CAD，再点概览「立即检测」。核对已安装版本独立展示，运行与连接状态如实反映。启动一个 CAD 实例后重试。核对等待期间按钮不可重复触发，窗口仍可导航与缩放。强制失配可在设置中选择另一预期版本再检测，核对实际连接的版本与分析限制提示。
- 在 Windows 10 和 11 的 100%、125%、150% 缩放分别核对。优先使用 1080p 及浅色不透明主题，并核对深色和 Windows 11 Mica 降级。作业页滚动到最后，展开高级设置。用较长的模型路径和配置名测试文字换行、控件可访问与键盘操作。

在原生 Windows PowerShell 运行以下命令。第一个命令启动应用，并输出其 PID。第二个命令使用同一窗口。

```powershell
.\tests\Capture-DesktopUi.ps1 -ExpectedScale 125 -Page Overview -NavigationMode Expanded -RunDetection -CaptureLabel expanded
.\tests\Capture-DesktopUi.ps1 -ExpectedScale 125 -ExistingProcessId 1234 -Page Assignment -NavigationMode Collapsed -CaptureLabel assignment-collapsed
```

需要记录高级设置时，可手动打开并滚动到要保存的位置，使用 `-ExistingProcessId 1234 -Page Current -CaptureLabel assignment-advanced`。截图写入 `ui-evidence`。

Linux 云端可构建 Windows x64 产物并验证规则编辑数据及 SQLite 工作流。Windows WPF 启动、布局、截图和 SOLIDWORKS 实际配置读取分别记录，仍待现场验证。


同一零件可一边从磁盘选，一边从 SOLIDWORKS 选。真机验证时按「开始对照 → 重新选件 → 开始对照」连续执行三次。确认源文档一直保持打开，结果成功显示，目录清理信息只出现在开发模式。若关闭状态未确认，软件会保留对应副本，便于核查 CAD 状态。
