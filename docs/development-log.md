# 开发记录

## 2026-11-18 · 阶段 0 云端交付

- 在 Linux x86-64 建立 VS2022 解决方案，交叉编译 x64 .NET Framework 4.8 命令行 Probe，产出 Windows 便携包。
- 选择从目标 SOLIDWORKS 安装目录加载 Interop，按官方类型元数据调用接口，便于在同一二进制中诊断 SW2025/2026。实际 COM 调用与 Interop 兼容性需要真机确认。
- 源文件先计算哈希，再在独立工作区使用唯一名称的只读副本。面积指标的口径是所有固体实体的表面积，不计独立曲面。质量输出采用单实体、有零件级材料、无已知质量覆盖且 CAD 返回正有限值的保守条件。
- 多实例期间探针停止连接，由用户在 CAD 中保留目标实例。按 PID 选择 ROT 对象可在后续阶段评估。
- 阶段 0 的 Utilities 功能验证限于取得对象和比较接口。首次几何运算、报告输出和许可结果尚待双样本。
- 纯逻辑测试与 PE 产物检查见 [云端验证记录](cloud-verification.txt)。未执行 Windows 运行时或 CAD 实测，阶段 1 暂未启动。

## 2026-11-18 · 阶段 1 云端实现

- 将阶段 0 的 COM 操作提取到 `SWGrade.SolidWorks`，Probe 和中文 WPF 分析器共用。桌面调用在后台 STA 线程运行，以会话互斥锁限制并发。
- 新增结构化模型结果和 JSON，使用 SI 单位与可空度量。模型证据不足时，界面保留已读取的部分和解释，连接或读取失败显示诊断。
- 命令行可选导出同一 JSON，便于真机运行 `tests/Verify-ModelRead.ps1` 重复校验。桌面 JSON 导出与命令行均使用新文件。
- 记录 x64 .NET Framework 4.8 WPF/Probe 构建和纯逻辑结果。阶段 1 的 Windows 实际显示、COM、样本读数和无材料用例仍待验收。

## 2026-11-18 · 主流程云端预发布

- 阶段 2。建立标准件预检、配置映射、同修订版约束及参数对照。抑制状态使用官方 `IFeature::IsSuppressed2` 的当前配置数组，未知状态按待复核处理。几何接口探测维持独立。
- 阶段 3。加入纯 C# 权重与容差规则、几何分档规则、教师确认留痕和 HTML 报告。生产流程的几何分值保留待复核。
- 阶段 4。加入班级导入、重复提示、顺序任务与停止边界、失败/取消重试、记录恢复、SQLite 历史和 CSV。测试台使用带 MOCK 标记的 CAD 代替件及真实 SQLite，本地测试记录和发布版分离。
- 阶段 5。以 `win-x64` 目标构建桌面程序，打包 Windows 原生 SQLite 依赖，并提供现场验收矩阵。发布包是现场修改和首验的起点，Windows/CAD 真实运行状态按现场记录更新。

## 2026-11-18 · 0.2.1 预览

- 增加 SOLIDWORKS 当前零件和已打开零件选择器，并接入单件分析、标准件选择及作业导入。
- 活动文档用于定位路径、保存状态和配置。度量使用原流程中的磁盘只读副本，JSON 记录打开文档来源及需保存状态。
- 新增命令行 `--active` 与 `--list-open`。Windows 上的文档列表、真实读取和交互仍待真机验收。

## 2026-11-18 · 0.3.0 预览

- 按用户白板草图接通启动连接、单双件选择及分析结果。作业批改分为左侧提交和右侧详情，作业配置和评分规则沿用左右布局。
- 添加实际 CAD 显示网格预览以及同一视角下的零件切换、旋转、缩放和平移。网格及真实 WPF 交互仍需 Windows 现场验证。
- 双件参数对照复用测量证据与容差计算，支持明确配置映射，并可导出 JSON。几何差异和局部三维标记待真机验证。

## 2026-11-18 · 0.4.0 预览

- 接入 WPF UI 4.3.0（net472 资产运行于现有 net48）。沉浸式顶栏、六项导航、概览、记录页和设置已重构。记录来自现有 SQLite，本机诊断仍使用原 CAD 会话。
- 支持默认浅色、可选深色、原生 Mica 和不透明 Fluent 背景。窗口清单设置 PerMonitorV2。新增真实 Windows 桌面截图脚本，四种 DPI 的实际显示在真机核验。

## 0.4.1-preview.1 作业管理与局部导航

- 作业设置分为五个单列分组。实际 CAD 配置目录驱动下拉框，默认使用文件保存的活动配置。学生配置无法匹配时进入待复核，可指定配置后重试。规则与历史的数据格式兼容。
- 相对容差以百分比编辑。预设及三种工程单位编辑都转回原规则值，实时例子调用原评分公式。保留人工复核权重或转给参数由教师决定。
- 使用原生独立标题栏。侧栏 232/60 DIP 可切换，底部固定设置。「立即检测」复用 STA、系统和真实 COM 探针，分开报告安装、运行、连接与分析所需条件。
- Windows 现场测试按 [作业管理与窗口验收](assignment-editor-acceptance.md) 执行。
