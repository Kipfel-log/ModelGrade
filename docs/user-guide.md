# 阶段 1 单件分析器

## 日常操作

1. 从便携包的 `bin` 打开 `SWGrade.Desktop.exe`。「概览」打开后会自动检测，也可点击「立即检测」。设置页可重新检测并查看详情。
2. 启动一个 SOLIDWORKS 实例，用与 CAD 相同的 Windows 用户和权限操作 SWGrade。在「设置」开启「开发模式」并展开「详细诊断」查看 Windows build、注册、实际 CAD 版本和 Utilities 接口状态。多实例时由操作者手动保留目标实例。
3. 选择独立 `.SLDPRT`。CAD 版本可让程序识别，也可手工指定。配置名留空使用文件中的活动配置，指定配置时按实际名称输入。
4. 在引导页选择当前件，点「分析当前件」。界面显示实测实体数、实体体积/表面积、配置、特征类型摘要、可用材料及质量属性。普通零件的重建状态来自 CAD。钣金切换时由 SOLIDWORKS 在内存中重建工作副本。测量暂不可用时，以「待复核」展示。质量和密度缺值时，JSON 保留 `null`。技术详情可在设置的开发模式查看。
5. 「复制 JSON」适合粘贴到本地编辑器。「导出 JSON」写入新的 `.json` 文件。导出的体积为 m³、面积为 m²、质量为 kg、密度为 kg/m³。JSON 含源路径和 SHA-256，分享前按实际需要处理本地路径。

分析在后台 STA 线程执行，单次只处理一份文件。桌面程序与探针在同一 Windows 会话串行使用 CAD。收到未完成提示时，可根据诊断核查正在运行的实例、许可、文件依赖及配置。若 COM 调用长时间等待，请查看 CAD 是否有模态对话框。工具会等待当前调用返回并清理临时文档。

## 真机验收

先按 [阶段 0 清单](environment-check.md) 确认真正的连接和样本读取，再验收桌面程序。

- CAD 未启动时打开桌面应用，点击检测，确认显示明确诊断。Windows 10 + SOLIDWORKS 2026 组合应触发官方支持边界提示。
- 在 Windows 11 + SOLIDWORKS 2026 上读取同一份样本两次，与 CAD 原生质量属性视图核对单位和值。检查两次结果一致，原文件的 SHA-256 和最后写入时间保持一致。确认工具运行前打开的 CAD 文件仍在。
- 用无材料样本确认质量和密度待复核。用错误配置名、损坏文件确认显示失败原因。尝试从零实体样本导出，核对有证据的数据和缺失字段。
- 验证 JSON 复制、导出以及拒绝覆盖已有文件。核对界面显示和导出数据来自同次读取。
- 确认界面在 Windows 10 22H2 和 Windows 11 下启动，文字、布局和操作可用。对另外两个目标 CAD 组合分别记录结果。

便携包根目录中的 Windows PowerShell 脚本会调用真实 Probe 两次，比较导出的记录、源文件 SHA-256 和最后写入时间。

```powershell
.\tests\Verify-ModelRead.ps1 -ExpectedYear 2026 -Model 'C:\Samples\part.SLDPRT'
```

可选参数 `-Configuration '配置名'` 和 `-WithoutMaterial` 分别校验指定配置和无材料用例。从源码目录运行时用 `-ProbePath` 指向构建后的探针。脚本仅在两次真实进程均成功后打印 PASS。

## 建立作业与批量批改

在「作业管理」点「新建作业」，选择标准模型，然后从下拉列表选择用于批改的版本。默认选中文件中保存的活动配置。学生件优先查找同名配置。如果班级约定了别的名称，可在高级设置填写。个别学生无法匹配时，打开该学生的结果，选择其配置，再继续队列。

通常只需选标准件和误差要求，然后保存。要检查建模步骤时，勾选「还要检查指定建模操作」，直接选要考查的操作。选择标准件后，用文件名填入作业名称，可随时修改。

高级设置中可以调整逐项容差、评分权重、质量和材料要求。严格、标准、宽松是待样件验证的建议初始值。权重合计为 100。「保存作业并保留待复核分」确认留下程序尚无法评估的分值，重新分配可在高级设置完成。保存时固定标准件内容及规则，可以「沿用当前规则」另存新版本。

保存或重新打开作业后，先点「标准件预检」确认配置和度量，预检通过后可开始批改。可导入一个或多个文件，或扫描文件夹本层的 `.SLDPRT`。软件从符合格式的文件名尝试提取学号和姓名。同内容会提示并保留各自的提交记录。选中一行，可在「学生信息与复核」修正学号和姓名。

「暂停」在当前文件处理完后生效。「取消剩余」保留已处理结果，取消未开始的项。失败和取消可通过「重试所选」重新加入队列。为避免改变提交证据，文件内容变化后请重新导入新文件。查看「证据和执行记录」可找到失败原因、任务 ID、哈希和 CAD 版本。任务异常中断后再次打开，运行中的项会转为可重试的失败。

在「逐项对照」查看标准值、学生值、误差、有效容差、已评估得分和未评估分值。教师在复核页填写终评和原因，历次确认均保留。CSV 适合班级表，HTML 包含单件明细与复核记录。导出使用新文件，也可在「设置」先做连接检测，再从「详细诊断」导出诊断。

历史数据库存放在 `%LOCALAPPDATA%\SWGrade\Teacher\swgrade.sqlite3`。用「本地数据」打开位置。备份前关闭 SWGrade。数据库和班级导出均保存在指定的本地目录。

## 从 SOLIDWORKS 中直接选零件

「单件分析」中的「使用 CAD 当前零件」会识别 SOLIDWORKS 的活动零件。「从已打开零件选择」会列出当前会话中的可见零件、活动配置和保存状态。选好后点击下方分析按钮。未填写配置时，这两个入口使用 CAD 中所选文档的活动配置读取磁盘副本。若该配置尚未保存到磁盘，读取会报配置不匹配。

「作业管理」可「从 SOLIDWORKS 选择」标准件，「批改与历史」可「导入 CAD 零件」。作业仍固定已保存文件的哈希，批改使用规则配置。

打开的原文档由 SOLIDWORKS 保持。SWGrade 读取磁盘上已保存的 .SLDPRT 的只读临时副本。新建未保存的零件需要先保存。CAD 的需保存标志会在选择列表、单件结果和 JSON 中体现。

命令行也可复核这两个入口。

```powershell
.\SWGrade.Probe.exe --list-open
.\SWGrade.Probe.exe --active --expect 2026
```

## 参考件与当前件

概览展示连接、CAD 版本、系统与最近批改。在设置启用开发模式后可查看技术诊断。左侧导航可进入模型分析、作业管理、批量批改或批改记录。

单件分析引导页的两边都支持选择文件、从 CAD 已打开零件选择、使用 CAD 当前零件。中间的「互换」同时交换两个文件及其配置。仅选择当前件时，使用单件读取流程。加选参考件后，结果包含两份真实读取记录和参数对照。配置不同需要明确填写对应配置名。

结果页左侧把当前配置与参考配置分开展开。常用字段包括体积、实体表面积、面数、实体数量、材料和可核实的质量。其下的「需要关注」列出实际差异和影响判断的问题。「参数对照」查看默认容差下各项对比。「建模特征」优先显示常用建模操作的启用数，展开全部类型可找到作业规则用名。

选择两件后，默认按原始 CAD 坐标比较。切换「比较坐标」会重新计算，结果页会标出实际采用的坐标。

- 作业允许学生从不同的草图基准面建模时，在「高级设置 → 几何比较坐标」选「按基准对齐」，打开「选择标准件基准」。在模型上依次点出三个法向独立的外侧平面，或用列表选择。作业保存后，批改自动沿用同一组基准。
- 选择确定姿态与原点的稳定外侧面。把题目要检查的孔、槽和局部尺寸留给比较。程序会在学生件中寻找外侧面并用其他外侧平面核对姿态。找不到可靠的对应，或几个可能摆法会把学生几何放到不同位置时，几何分进入人工复核。
- 单件分析选「按基准对齐」时会打开参考件基准选择器。保存三个基准面后可开始对照，或在结果页直接重新比较。也可在「评分试算」选匹配的作业，点「按此作业基准重新比较」。当前适用于有足够外侧平面的普通单实体。
- 旧作业按保存时的坐标规则批改。复制使用旧坐标方式的作业时，需要在高级设置为新作业选择原始 CAD 坐标或基准对齐。

普通单实体的差集验证通过后，红色是当前件多余，蓝色是当前件缺少，灰色是交集。「完整叠加」默认高亮被遮挡的差集，可关闭「高亮遮挡差集」查看正常遮挡效果。「仅多余」「仅缺少」会自动聚焦对应实体。左键拖动旋转，右键拖动平移，滚轮缩放，也可以单独查看当前件或参考件。若两种坐标都未取得可验证差集，可查看灰色单件模型。

选择「偏差云图」并计算后，可在「当前件」或「参考件侧」点取，设置以 mm 为单位的容差与范围。绿色对应容差带，灰色采样面片待核实。在斜视下更容易看到孔壁上的偏差。

「评分试算」可选择已保存的作业。参考件和配置匹配后，按批量引擎显示各项得分、实测值、容差及待复核的分值。试算时请为「比较坐标」选择该作业保存的策略。试算不会生成正式批改记录。


## 钣金对照

「模型分析」的「零件类型」默认自动识别。可手动选「按钣金检查展开图」或「按普通零件处理」。自动识别使用 SOLIDWORKS 的钣金实体及当前配置的钣金、平板型式特征。单实体钣金可查看折弯态和展开图，展开图支持正视、叠加和仅看差异。轮廓、孔位及开槽可以根据近似着色进一步核对。「建模特征」也列出平板型式、展开折弯和折叠。展开视图比较实体外形，工程图中的弯线与注释需另查。两件应采用一致的固定面和零件坐标。

创建作业时可在「高级设置」手动指定零件类型。自动模式根据标准件决定是否要求展开图。几何分要求折弯和展开均通过。展开尺寸证据不足时标为待复核。多实体、导入后无平板型式、展开失败均需复核。切换在工作副本上完成，CAD 关闭副本时不保存。


## 通知

操作通知叠放在主窗口右侧，最新一条在底部。每条都显示触发时间。点 × 可以关闭该条，点「清除全部通知」可清空。普通完成提示通常在约 7 秒后自动关闭，警告和错误会保留到手动关闭。运行中的进度、SOLIDWORKS 当前连接状态及批改结果仍在对应页面显示。
