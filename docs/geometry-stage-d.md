# 阶段 D · 几何与三维验收

验收在 Windows 11 26H2 x64 与 SOLIDWORKS 2026 SP2.1（修订版 34.2.1）上完成。试件为本机用 SOLIDWORKS 建立的独立单实体，主要采用 40 × 30 × 4 mm 偏心孔板。用已打开的参考件验证了原文件及文档状态保护。

## 执行命令

```powershell
dotnet build SWGrade.sln -c Release -p:Platform=x64
dotnet run --project tests/CloudChecks -c Release
dotnet run --project tests/WorkflowChecks -c Release
```

Release 构建 0 警告、0 错误。CloudChecks 49 项、WorkflowChecks 100 项通过。两套回归检查验证纯逻辑、规则、SQLite 和模拟队列，真机数据由独立测试取得。

用 [阶段 A](geometry-stage-a.md) 的真机脚本验证同件、同形异文件、移孔、平移和旋转。主程序离屏测试调用实际模型分析入口、实体视图控件和试算。批量测试使用实际桌面 CAD 读入组件与单独的 SQLite 库。

## 实物结果

| 场景 | 检查结果 |
| --- | --- |
| 同文件同配置、不同文件同实体 | 双向差集零；不同剖分的实际 CAD 网格也可核对。独立地把同一实体剖分为 344 面和 2264 面。 |
| 同形平移与 37° 旋转 | 原坐标检出位移；刚体对齐通过后两侧差集均为零。 |
| 移动 Ø4 mm 通孔 | 缺失、多余各 50.265482 mm³。 |
| 新增 Ø3 mm 通孔，复用已验证放置 | 缺失 28.274334 mm³，多余 0 mm³。缺失和交集都有可用网格。 |
| 删除 Ø4 mm 通孔 | 缺失 0 mm³，多余 50.265482 mm³。 |
| 板宽增加 2 mm | 缺失 0 mm³，多余 240 mm³。 |
| 相切与不相交 | 两侧差集保留各自总体积，交集为零。 |
| 配置不匹配、损坏零件、多实体、钣金 | 正常拒绝实体证据并保留复核状态。 |
| 20 份真实批改 | 均完成实体评估；批量与试算分数逐份一致。实际队列通过暂停、继续、取消剩余及 SQLite 重开。通过标记一个中断条目验证恢复与真实 CAD 重试。 |
| 源文件和资源 | 比较前后各样本 SHA-256、最后写入时间和 CAD 可见文档列表一致。批量验收结束时没有遗留临时零件文件，观测到一个延迟清理的空目录。 |

实体视图验证了红蓝单侧、灰色交集、完整叠加与透明参考件。WPF 离屏渲染覆盖 96、120、144 DPI。

以同一移孔试件验证连续云图。学生件有效采样值约为 −1.333 至 +1.769 mm，参考件约为 −1.083 至 +1.333 mm。两侧都检出缺失区域。离屏检查覆盖容差和色带范围重着色、局部点击读数、缩放后读数、切换到参考件时清除旧读数，以及源文件 SHA-256、最后写入时间和已打开文档状态。读数为相邻已查验采样值的插值，无法确认符号的区域保持灰色。

钣金样本通过主程序取得展开网格与 SOLIDWORKS 平面法向，源文件与已打开文档状态保持一致。

## 环境边界

本机只有可运行的 SOLIDWORKS 2026。SOLIDWORKS 2025、Windows 10、真实桌面缩放与鼠标交互仍需对应环境。当前真机运行只验证了本轮控制样本及指定队列。
