# 评分规则

每次保存作业都会固定标准件 SHA-256、配置映射和规则快照。「沿用当前规则」会生成一份可改的草稿，保存后形成新作业。标准件在每次开始或继续队列时核对文件哈希，在一次运行中复用同一份实测快照。标准件和学生件的 CAD 修订版必须一致。

## 参数与特征

- 绝对误差为 `abs(student - standard)`。有效容差为 `max(绝对容差, 相对容差 × abs(标准值))`。等于阈值视为通过。参考为零时，相对误差留空。
- 体积与实体表面积使用各自容差。质量和零件级材料由教师选配。缺失材料或质量属性保留为待复核。启用「要求单实体」后，学生实体数作为独立参数检查。
- 参数权重在启用的参数检查之间平均分配到 0.01 分，余数依检查顺序分配。教师可在任务开始前修改草稿中的三类权重。
- 默认比较同名配置。允许在作业规则中分别指定标准和学生配置名称。未确认映射、CAD 修订版不同、模型有影响数据的打开警告或待重建状态时，结果需复核。
- 特征规则核对指定 SOLIDWORKS API 类型在当前配置中是否存在。只把未压缩的特征作为通过证据。压缩状态或遍历结果不足以证明缺失时保留待复核。类型存在仅证明满足该条操作要求。几何与特征质量需另有证据。
- 「指定过程」要求配置至少一项特征类型及正权重。结果优先模式允许不指定过程。没有特征规则但分配了特征分值时，该部分留待教师复核，也可在新作业中将其设为 0。

## 几何与终评

几何权重默认 60 分，目前留给教师复核。规则快照可选通过/不通过、分档、教师复核。分档每行填上限和得分比例，差异率阈值递增，得分比例递减或持平。几何引擎只在提供真实且已验证的差集证据时计算差异率，此版本没有生产几何结果接入。

逐项结果分别为通过、未通过、不计分、待复核或错误。失败的 CAD 读取有独立任务状态，不会写入成绩。已经评估的扣分只针对有证据的项。待复核的分值不作比例换算。教师确认终评时须填写原因，自动证据和每次人工成绩及 UTC 时间分别保留。

同一作业可保存多个同内容提交。源文件变化后请重新导入，以保留原记录和新记录。修改标准件后应新建作业快照。
